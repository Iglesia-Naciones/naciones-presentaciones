# Naciones Presentaciones — nueva plataforma

Interfaz de operador reorganizada en cuatro paneles: biblioteca, letras, fondos/estilos y vista previa/acciones.

## Instalación
1. Descarga y descomprime el ZIP.
2. Reemplaza los archivos del repositorio con los de esta carpeta.
3. Conserva `manifest.webmanifest` y `sw.js` existentes si no están incluidos en el paquete.
4. Publica desde GitHub Pages y recarga con Ctrl+F5.

## Datos locales
La aplicación conserva IndexedDB `naciones-presentaciones`, versión 1, y las tiendas `media` y `songs`. No borres los datos del sitio. Se recomienda exportar un respaldo antes de actualizar.

## Alcance de esta entrega
Incluye biblioteca local, edición básica de canciones/estrofas, listas, historial, fondos de imagen/video, estilos tipográficos, transiciones configurables, vista previa, ventana de proyección, acciones rápidas y respaldo JSON. Es una primera transformación funcional; debe probarse en el equipo de operación y ajustarse con los resultados.
