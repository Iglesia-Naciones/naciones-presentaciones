NACIONES PRESENTACIONES PRO — INSTALACIÓN

ARCHIVOS:
- index.html
- styles.css
- app.js
- sw.js
- README.md

PASOS:
1. Descarga y descomprime el ZIP.
2. Sube TODOS los archivos a la raíz de tu repositorio GitHub Pages y acepta reemplazar.
3. Espera a que termine el despliegue.
4. Abre el sitio en HTTPS, recarga con Ctrl+F5.
5. Permite ventanas emergentes.
6. Pulsa “Proyección” y mueve esa ventana a la pantalla del público. Pulsa F11 para pantalla completa.
7. Pulsa “Escenario” para abrir una ventana independiente para monitores de escenario.

DATOS:
- La base `naciones-presentaciones` se actualiza de versión 1 a 2.
- Conserva las tiendas antiguas de media y songs; añade presentations y playlists.
- NO borres los datos del sitio ni IndexedDB.
- Descarga un respaldo desde “Respaldo” antes de actualizar.

PRUEBA:
Antes de usar en vivo, prueba importar archivos, guardar una canción, crear una presentación, cambiar diapositivas, pantalla negra, proyección y escenario.
